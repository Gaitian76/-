## 四、学习主线提示

这门课的结构很清楚，可按四条线复习：

1. **共同基础**（第 1 章）：测量误差、精度、不确定度、静态/动态特性、标定——后面每一类传感器都在这套语言下描述。
2. **按工作原理分类的传感器**（第 2–5 章）：电阻式 → 变电抗式 → 光电式 → 电动势式。
3. **按被测参数分类的检测系统**（第 6–9 章）：温度 → 流量 → 物位 → 成分。
4. **共性技术与新发展**（第 10 章）：误差修正、MEMS、虚拟仪器、无线传感器网络、数据融合、软测量。

第 1 章是全书的地基，也是计算题（误差、不确定度）最集中的地方。
