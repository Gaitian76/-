## PH.1.6 · 切向加速度与法向加速度
课程：物理学上；章节：第1章 质点运动学；证据等级：知识库明确关系

【物理学上】第1章 质点运动学 · 切向加速度与法向加速度 · 大一
定义：加速度分解：切向改变速率、法向改变方向
关键公式：at = dv/dt（切向，改变速率）；an = v²/R = ω²R（法向，指向圆心）；a = √(at² + an²)
适用条件：一般曲线运动同样适用（用曲率半径）。
易错点：法向加速度方向始终指向圆心而非向外。
要点：切向分量只改变速率、法向分量只改变方向。匀速率圆周运动 at=0、仅有 an；一般曲线运动同样适用（用曲率半径）。
解题方法：① 求瞬时速率 v；② 切向加速度 at=dv/dt（只改变速率）；③ 法向加速度 an=v²/ρ，圆周运动时 ρ=R（只改变方向）；④ 总加速度大小 a=√(at²+an²)，方向与速度夹角 θ=arctan(an/at)。
典型例题：质点沿半径 0.5m 的圆周运动，某瞬时速率 2m/s，速率变化率 1m/s²。求总加速度。 解：at = 1m/s²，an = v²/R = 4/0.5 = 8m/s²。a = √(1+64) = √65 = 8.06m/s²，与速度方向夹角 arctan(8/1) = 82.9°（指向圆内）。
常见问法：为什么转弯有加速度、向心加速度怎么算、加速度怎么分解
跨课程后续：《工程力学》第6章 点的运动学和刚体的基本运动（物理学第1章「质点运动学」与工程力学第6章「点的运动学」为同名内容）

## PH.2.1 · 牛顿运动定律
课程：物理学上；章节：第2章 牛顿运动定律；证据等级：知识库明确关系

【物理学上】第2章 牛顿运动定律 · 牛顿运动定律 · 大一
定义：第一定律（惯性）、第二定律（F=ma）、第三定律（作用与反作用）
关键公式：第一定律：不受外力时保持静止或匀速直线运动；第二定律：F = ma（动量形式 F = dp/dt）；第三定律：F12 = −F21；非惯性系：F + F惯 = m·a′，F惯 = −m·a0
易错点：惯性力无施力物体、无反作用力，是虚拟力，不遵循第三定律。
要点：牛顿定律只在惯性系成立；非惯性系中引入惯性力（平动加速系的 −ma0、转动系的离心力与科里奥利力）使 F=ma 形式上成立。
解题方法：① 确定参考系是否惯性系，非惯性系需加惯性力；② 对研究对象作受力分析画受力图；③ 建坐标系列 ΣF=ma 的分量方程；④ 解方程求加速度；⑤ 结合运动学求速度与位移。
典型例题：质量 2kg 的物体在光滑水平面上受水平拉力 10N。求加速度，以及受 4N 摩擦阻力时的加速度。 解：a = 10/2 = 5m/s²。加摩擦后 a = (10−4)/2 = 3m/s²。
常见问法：受力怎么算加速度、为什么刹车会前倾、惯性是什么
跨课程后续：《工程力学》第9章 质点动力学基本方程（工程力学第9章「动力学基本定律」「质点运动微分方程」直接建立在牛顿运动定律之上）

## PH.3.2 · 动量守恒定律
课程：物理学上；章节：第3章 动量守恒定律和能量守恒定律；证据等级：知识库明确关系

【物理学上】第3章 动量守恒定律和能量守恒定律 · 动量守恒定律 · 大一
定义：系统合外力为零时总动量保持不变
关键公式：质点系：Σ∫F外 dt = Δp总；ΣF外 = 0 时 Σmi·vi = 常矢量（各分量可单独守恒）
易错点：动量是矢量，须按分量处理；内力不能改变系统总动量。
要点：动量定理给出冲量等于动量增量；动量守恒的条件是合外力为零，或碰撞、爆炸等瞬时过程中外力远小于内力可近似守恒。
解题方法：① 明确系统（含哪些物体）；② 判断合外力是否为零，或碰撞、爆炸等瞬时过程内力远大于外力可近似守恒；③ 写守恒式 Σmivi = 常量；④ 按坐标轴投影成标量方程；⑤ 与能量关系联立求解。
典型例题：质量 2kg 的小球以 3m/s 运动，与静止的 1kg 小球发生完全非弹性碰撞。求碰后共同速度。 解：动量守恒：2×3 + 1×0 = (2+1)v → v = 6/3 = 2m/s。碰后动能 ½×3×4 = 6J，仅为碰前的 2/3，损失部分转为内能。
常见问法：碰撞后速度怎么算、动量什么时候守恒、火箭为什么能飞
跨课程后续：《工程力学》第10章 动量定理（物理学 3-1「质点和质点系的动量定理」与工程力学第10章动量定理直接衔接）；《工程力学》第11章 动量矩定理（物理学 4-3「角动量 角动量守恒定律」与工程力学第11章动量矩定理直接衔接）；《工程力学》第12章 动能定理（物理学 3-4「动能定理」「机械能守恒定律」与工程力学第12章动能定理直接衔接）

## PH.3.5 · 动能定理
课程：物理学上；章节：第3章 动量守恒定律和能量守恒定律；证据等级：知识库明确关系

【物理学上】第3章 动量守恒定律和能量守恒定律 · 动能定理 · 大一
定义：合外力对质点做的功等于质点动能的增量
关键公式：质点：W合 = ΔEk = ½mv² − ½mv0²；质点系：W外 + W内 = ΔEk；功能原理：W外 + W非保内 = ΔE；机械能守恒：W外 + W非保内 = 0 时 Ek + Ep = 常量
易错点：功与动能变化都依赖参考系；势能需先指定零势能面。
要点：动能定理是力对空间的累积（功）等于动能增量，须在惯性系中计算；机械能守恒要求只有保守力（重力、弹力、万有引力）做功。
解题方法：① 取研究对象，确定始末状态；② 计算所有外力的功（变力用积分）；③ 用 W合=½mv²−½mv0² 列方程；④ 求速率；⑤ 势能已知时优先用机械能守恒。
典型例题：质量 2kg 的物体从静止受恒力 10N 作用沿光滑水平面移动 3m。求末速度。 解：W = 10×3 = 30J，由 ½mv² = 30 得 v = √30 = 5.48m/s。（物体水平运动，势能不变）
常见问法：做功怎么变成速度、能量守恒怎么用
跨课程后续：《工程力学》第10章 动量定理（物理学 3-1「质点和质点系的动量定理」与工程力学第10章动量定理直接衔接）；《工程力学》第11章 动量矩定理（物理学 4-3「角动量 角动量守恒定律」与工程力学第11章动量矩定理直接衔接）；《工程力学》第12章 动能定理（物理学 3-4「动能定理」「机械能守恒定律」与工程力学第12章动能定理直接衔接）

课程：物理学上；章节：第3章 动量守恒定律和能量守恒定律；证据等级：知识库明确关系

## PH.4.3 · 力矩、转动定律、转动惯量
课程：物理学上；章节：第4章 刚体转动和流体运动；证据等级：知识库明确关系

【物理学上】第4章 刚体转动和流体运动 · 力矩、转动定律、转动惯量 · 大一
定义：M=Jβ，转动惯量是刚体转动惯性的量度
关键公式：M = Jβ；J = Σmi·ri²（连续体 J = ∫r²dm）；平行轴定理 J = JC + md²；转动动能 Ek = ½Jω²
易错点：J 与转轴位置、方向有关，换轴须重算或用平行轴定理；M、β、J 必须对同一固定轴而言。
要点：M = Jβ 是转动情形下牛顿第二定律的对应形式，J 反映质量对转轴的分布。
解题方法：① 明确转轴，求该轴的合外力矩 M；② 求对同一轴的转动惯量 J（换轴时用平行轴定理 J=JC+md²）；③ 由 M=Jβ 求角加速度；④ 结合转动运动学求 ω 与 θ；⑤ 用转动动能 ½Jω² 处理能量问题。
典型例题：均质圆盘质量 10kg、半径 0.2m，绕中心轴转动，受恒力矩 2N·m。求角加速度；转动 2 圈后角速度。 解：J = ½mR² = 0.5×10×0.04 = 0.2kg·m²，β = M/J = 10rad/s²。转 2 圈 θ = 4π，ω = √(2βθ) = √(2×10×12.566) = √251.3 = 15.85rad/s。
常见问法：转动惯量怎么算、转盘为什么难转起来、力矩和转动的关系

## PH.4.5 · 角动量与角动量守恒定律
课程：物理学上；章节：第4章 刚体转动和流体运动；证据等级：知识库明确关系

【物理学上】第4章 刚体转动和流体运动 · 角动量与角动量守恒定律 · 大一
定义：质点和刚体的角动量，合外力矩为零时角动量守恒
关键公式：质点对定点：L = r × p，M = dL/dt；刚体定轴转动：Lz = Jω，M外 = dLz/dt；M外 = 0 时 Jω = 常量
易错点：守恒条件是合外力矩为零而非合外力为零；角动量与力矩须对同一参考点（轴）计算。
要点：角动量守恒指系统所受合外力矩为零时总角动量不变，典型现象是定轴转动 J 减小则 ω 增大（如花样滑冰收臂）。
解题方法：① 选定参考点或转轴；② 求系统的角动量（定轴转动 L=Jω）；③ 判断对该点（轴）的合外力矩是否为零；④ 为零则 J1ω1 = J2ω2，据此求新的 ω；⑤ 注意角动量必须对同一参考点计算。
典型例题：某转台转动惯量 0.2kg·m²、角速度 10rad/s。若通过改变质量分布使转动惯量变为 0.1kg·m²，求新的角速度。 解：轴向外力矩为零，角动量守恒：J1ω1 = J2ω2 → 0.2×10 = 0.1×ω2 → ω2 = 20rad/s。这是花样滑冰收臂加速的同类问题。
常见问法：为什么收臂会转得更快、角动量怎么守恒

## PH.5.1 · 电荷的量子化、电荷守恒定律与库仑定律

定义：点电荷间作用力的平方反比律

## PH.5.4 · 电场强度通量与高斯定理
课程：物理学上；章节：第5章 静电场；证据等级：知识库明确关系

【物理学上】第5章 静电场 · 电场强度通量与高斯定理 · 大一
定义：闭合曲面的电通量等于面内电荷量除以真空电容率
关键公式：∮S E·dS = (1/ε0)·Σq内；有介质时 ∮D·dS = Σq0；微分形式 ∇·E = ρ/ε0
易错点：闭合面上的 E 是全部电荷（含面外）共同产生的，但通量只看面内电荷代数和；须利用球、柱、面对称性选高斯面。
要点：高斯定理反映静电场是有源场，电场线起于正电荷、止于负电荷。电通量只与面内净电荷有关，与面外电荷无关。

典型例题：半径 R=0.1m 的球面均匀带电 Q=1×10⁻⁹C，求球面处的场强。 解：取同心球面为高斯面：E·4πR² = Q/ε0 → E = kQ/R² = 9×10⁹×1×10⁻⁹/0.01 = 900V/m，方向沿半径（正电荷向外）。

## PH.5.9 · 电场强度与电势梯度
课程：物理学上；章节：第5章 静电场；证据等级：知识库明确关系

【物理学上】第5章 静电场 · 电场强度与电势梯度 · 大一
定义：等势面与场强的关系：场强等于电势梯度的负值
关键公式：Va = ∫a→∞ E·dl；E = −∇V = −(∂V/∂x i + ∂V/∂y j + ∂V/∂z k)；|E| = ΔV/Δn
易错点：电势零点可任选；等势面与电场线处处垂直。
要点：电势是描述静电场能量性质的标量，等于单位正电荷从该点移到零电势参考点时静电力做的功；因静电力做功与路径无关（∮E·dl=0），故可引入电势。 E 指向电势降低最快的方向。
解题方法：① 由电荷分布求电势 V（点电荷叠加或积分）；② 取等势面法向；③ 用 E=−dV/dn 求场强大小，方向指向电势降低最快方向；④ 已知 E 求电势时用 V=∫E·dl 沿任意路径（结果与路径无关）。
典型例题：平行板电容器两板相距 1cm，电势差 100V（视为匀强电场）。求板间场强。 解：E = ΔV/d = 100/0.01 = 10000V/m = 1×10⁴V/m，方向由高电势板指向低电势板。
常见问法：电势和电场什么关系、为什么电势降低方向是场强方向

## PH.6.5 · 电容、电容器
课程：物理学上；章节：第6章 静电场中的导体与电介质；证据等级：知识库明确关系

【物理学上】第6章 静电场中的导体与电介质 · 电容、电容器 · 大一
定义：孤立导体的电容、平行板电容器以及电容器的并联和串联
关键公式：C = Q/U；平行板电容器 C = εr·ε0·S/d；储能 W = ½CU² = ½QU = ½Q²/C；能量密度 we = ½ε0E²
易错点：电容器串并联公式与电阻相反；能量密度是场量，适用任意电场分布。
要点：电容只由几何结构和介质决定，与是否带电无关。能量密度表明能量储存在电场中，与 E² 成正比。
解题方法：① 由几何与介质求电容 C（平行板 C=εrε0S/d）；② 判断容器是否接入电源（接电源则 U 不变，断开则 Q 不变）；③ 用 Q=CU 求电荷，W=½CU²=½Q²/C 求储能；④ 串并联按与电阻相反的规律换算；⑤ 场强用 E=U/d，能量密度 ½ε0E²。
典型例题：平行板电容器 S=0.01m²、d=1mm、空气介质，充电至 100V。求电容、电荷与储能。 解：C = ε0S/d = 8.85×10⁻¹²×0.01/0.001 = 8.85×10⁻¹¹F ≈ 88.5pF。Q = CU = 8.85×10⁻⁹C。W = ½CU² = 0.5×8.85×10⁻¹¹×10⁴ = 4.43×10⁻⁷J。
常见问法：电容怎么算、电容器能存多少电、充电要多久

## PH.7.5 · 毕奥-萨伐尔定律
课程：物理学上；章节：第7章 恒定磁场；证据等级：知识库明确关系

【物理学上】第7章 恒定磁场 · 毕奥-萨伐尔定律 · 大一
定义：计算载流导线产生的磁场，含磁矩与运动电荷的磁场
关键公式：dB = (μ0/4π)·(I·dl×r̂)/r²；B = ∫dB；μ0 = 4π×10⁻⁷ T·m/A
适用条件：恒定电流、真空。
易错点：dB 方向由 dl×r̂ 决定（右手螺旋）；电流元不能单独存在，须对整个闭合回路积分。
要点：给出电流元产生磁场的规律，是静磁学的基础（地位类似库仑定律），可推出直线电流、圆电流等磁场。
解题方法：① 取电流元 Idl；② 判断 dB 方向（右手螺旋 dl×r̂）；③ 由 dB=(μ0/4π)·Idl·sinθ/r² 求大小；④ 对整个电流分布积分（利用对称性简化）；⑤ 常见结果记熟：长直导线 B=μ0I/(2πr)、圆电流中心 B=μ0I/(2R)。
典型例题：半径 0.1m 的圆形载流线圈通过电流 5A。求圆心处的磁感强度。 解：B = μ0I/(2R) = 4π×10⁻⁷×5/(0.2) = 6.283×10⁻⁶/0.2 = 3.14×10⁻⁵T，方向垂直于线圈平面，由右手螺旋判定。
常见问法：电流周围磁场怎么算、磁场是怎么产生的
跨课程后续：《电路》第6章 储能元件（物理学第7章「恒定磁场」是电路第6章「电感元件」的物理基础）

## PH.7.7 · 安培环路定理
课程：物理学上；章节：第7章 恒定磁场；证据等级：知识库明确关系

【物理学上】第7章 恒定磁场 · 安培环路定理 · 大一
定义：磁感强度沿闭合回路的积分等于穿过回路的电流代数和乘以 μ₀
关键公式：∮L B·dl = μ0·ΣI内；微分形式 ∇×B = μ0·j
易错点：环路积分只与环内电流（代数和，按右手定则定正负）有关，环外电流对积分无贡献但对环上的 B 有贡献；只适用于恒定电流。
要点：表明恒定磁场是有旋（涡旋）场，磁感线闭合。仅当电流分布具有轴对称、长直、螺线管等对称性时才便于用它求磁场。
解题方法：① 分析电流分布的对称性；② 选取合适闭合环路使 B 在环上大小恒定且方向沿环；③ 算环内电流代数和（按右手定则定正负，环外电流不计）；④ 由 ∮B·dl=μ0ΣI 解出 B。
典型例题：无限长直导线通过电流 10A。求距导线 2cm 处的磁感强度。 解：取半径为 r 的圆环为环路：B·2πr = μ0I → B = μ0I/(2πr) = 4π×10⁻⁷×10/(2π×0.02) = 2×10⁻⁶/0.02 = 1×10⁻⁴T。
常见问法：磁场怎么算、安培环路怎么选

## PH.8.1 · 电磁感应定律
课程：物理学上；章节：第8章 电磁感应 电磁场；证据等级：知识库明确关系

【物理学上】第8章 电磁感应 电磁场 · 电磁感应定律 · 大一
定义：法拉第电磁感应定律与判断方向的楞次定律
关键公式：ε = −dΦ/dt；N 匝线圈 ε = −N·dΦ/dt；负号表示方向由楞次定律确定
易错点：看的是磁通量变化率而非磁通量本身；Φ 的变化可由 B、面积或夹角变化引起。
要点：感应电动势大小等于磁通量变化率；电动势来源分动生（导体运动切割磁感线）与感生（磁场随时间变化产生涡旋电场）。
解题方法：① 确定回路及磁通量 Φ 的表达式；② 分析 Φ 变化的原因（B 变、面积变、夹角变）；③ 用 ε=−N dΦ/dt 求大小；④ 用楞次定律判断感应电流方向（反抗磁通变化）；⑤ 区分动生（切割磁感线）与感生（涡旋电场）。
典型例题：100 匝线圈内磁通量在 0.1s 内由 0.02Wb 均匀降到 0.01Wb。求感应电动势。 解：ε = −NΔΦ/Δt = −100×(0.01−0.02)/0.1 = 10V。方向由楞次定律确定：感应电流要反抗磁通减少，故与导致原磁场的电流同向。
常见问法：为什么会有感应电、发电机怎么发电、楞次定律怎么判断
跨课程后续：《电路》第10章 含有耦合电感的电路（物理学 8-3「自感和互感」直接对应电路第10章「互感」「变压器原理」「理想变压）

## PH.8.4 · 自感和互感
课程：物理学上；章节：第8章 电磁感应 电磁场；证据等级：知识库明确关系

【物理学上】第8章 电磁感应 电磁场 · 自感和互感 · 大一
定义：自感系数、互感系数与自感、互感电动势
关键公式：自感：Ψ = LI，εL = −L·dI/dt；互感：Ψ21 = M·I1，ε21 = −M·dI1/dt，且 M12 = M21
易错点：L、M 为正值，互感电动势正负取决于线圈绕向。
要点：自感系数 L 描述回路电流变化在自身回路中产生感应电动势的性质；互感系数 M 描述一个回路电流变化在另一回路中产生感应电动势的性质。二者只由几何形状、匝数和介质决定，与电流无关。
解题方法：① 判断是自感还是互感；② 自感用 εL=−L dI/dt，互感用 ε21=−M dI1/dt；③ L、M 由几何形状与介质决定，与电流无关；④ 注意互感电动势正负取决于线圈绕向（同名端）。
典型例题：自感系数 0.5H 的线圈中电流在 0.1s 内由 0 均匀增到 2A。求自感电动势。 解：εL = −L·dI/dt = −0.5×(2/0.1) = −10V，大小为 10V，方向反抗电流增大（即与电流方向相反）。
常见问法：电感是什么、变压器怎么工作、线圈为什么阻碍电流变化
跨课程后续：《电路》第10章 含有耦合电感的电路（物理学 8-3「自感和互感」直接对应电路第10章「互感」「变压器原理」「理想变压）

## PH.8.8 · 麦克斯韦电磁场方程组
课程：物理学上；章节：第8章 电磁感应 电磁场；证据等级：知识库明确关系

【物理学上】第8章 电磁感应 电磁场 · 麦克斯韦电磁场方程组 · 大一
定义：电磁场基本方程的积分形式，电磁场理论的统一
关键公式：∮S D·dS = Σq0；∮S B·dS = 0；∮L E·dl = −dΦB/dt；∮L H·dl = I0 + dΨD/dt；位移电流密度 jd = ∂D/∂t
易错点：位移电流不产生焦耳热。
要点：位移电流是麦克斯韦为修正安培环路定理、保证电流连续性而引入的变化的电场，不是电荷定向移动，可在电介质和真空中存在并能产生磁场。麦克斯韦方程组统一描述电磁场并预言电磁波。
解题方法：① 明确四个方程各自的物理含义（高斯电定律、磁通连续、法拉第定律、安培-麦克斯韦定律）；② 涉及变化电场时用位移电流补全安培环路定理；③ 判断场是否为无源（磁）或有源（电）；④ 判断是否为有旋场，据此选曲面积分或环路积分。
典型例题：平行板电容器充电过程中，板间电场变化率 dE/dt = 10¹²V/(m·s)。求板间的位移电流密度。 解：jd = ε0·dE/dt = 8.85×10⁻¹²×10¹² = 8.85A/m²。位移电流产生的磁场与传导电流在导线周围产生的磁场相衔接，保证电流连续性。
常见问法：电磁波怎么来的、位移电流是什么、四个方程各是什么
跨课程后续：《电路》第10章 含有耦合电感的电路（物理学 8-3「自感和互感」直接对应电路第10章「互感」「变压器原理」「理想变压）
