## EM.3.2 · 平面任意力系的平衡方程
课程：工程力学；章节：第3章 平面任意力系；证据等级：教材目录（章节结构）

【工程力学】第3章 平面任意力系 · 平面任意力系的平衡方程 · 大二
定义：一矩式、二矩式、三矩式三种形式的平衡方程及其适用条件
关键公式：一矩式：ΣFx=0, ΣFy=0, ΣM_A=0；二矩式：ΣFx=0, ΣM_A=0, ΣM_B=0；三矩式：ΣM_A=0, ΣM_B=0, ΣM_C=0
要点：三个独立方程只能解三个未知量。二矩式要求 A、B 连线不得与投影轴垂直；三矩式要求 A、B、C 三点不共线——附加条件是保证方程线性无关。选取投影轴与矩心时，尽量使每个方程只含一个未知量。
解题方法：① 取研究对象画受力图；② 建坐标系，选投影轴与矩心（尽量使每个方程只含一个未知量）；③ 列 ΣFx=0、ΣFy=0、ΣM=0（或用二矩式、三矩式）；④ 解方程并校核。
典型例题：简支梁 AB 长 4m，A 端铰支、B 端滚动支座，跨中受集中力 F=20kN。求支座反力。 解：ΣM_A=0：R_B×4 − 20×2 = 0 → R_B = 10kN。ΣFy=0：R_A + R_B − 20 = 0 → R_A = 10kN。
常见问法：支座反力怎么求、梁的反力怎么算、平衡方程怎么列
课内前置：《工程力学》第2章 平面基本力系
课内后续：《工程力学》第5章 空间力系

## EM.4.2 · 摩擦角与自锁现象
课程：工程力学；章节：第4章 摩擦；证据等级：教材目录（章节结构）

【工程力学】第4章 摩擦 · 摩擦角与自锁现象 · 大二
定义：摩擦角、摩擦锥的概念与自锁条件
关键公式：tanφm = fs；全反力与法线夹角 β ≤ φm 时平衡；自锁条件 α ≤ φm
要点：摩擦角是全反力偏离法线的最大角度，摩擦锥顶角为 2φm。自锁指无论主动力多大都无法产生相对滑动，即平衡与主动力大小无关（螺旋千斤顶、楔块夹紧即利用自锁）。注意摩擦角对应临界状态，不是任意时刻的实际偏角。
解题方法：① 判断接触面摩擦因数 fs，求摩擦角 φm=arctan fs；② 画全反力（法向力与摩擦力的合力）；③ 判断全反力与法线夹角是否 ≤φm；④ 若主动力作用线始终落在摩擦锥内则该物体自锁。
典型例题：物块置于倾角 α 的斜面上，静摩擦因数 fs=0.5。求物块不下滑的最大倾角。 解：自锁条件 α ≤ φm，φm = arctan0.5 = 26.57°。故 α ≤ 26.57° 时物块保持静止。
常见问法：物体为什么不下滑、自锁条件是什么、斜面多陡会滑

## EM.5.4 · 重心
课程：工程力学；章节：第5章 空间力系；证据等级：教材目录（章节结构）

【工程力学】第5章 空间力系 · 重心 · 大二
定义：重心坐标公式与组合法、负面积法求重心
关键公式：xc = Σ(mi·xi)/Σmi = ∫x dm / ∫dm，yc、zc 同理；均质物体重心与形心重合：xc = Σ(Ai·xci)/ΣAi
要点：重心是平行重力力系的中心。组合图形可用分割法或负面积（空穴）法计算。重心坐标依赖坐标系选取，但物理位置唯一。
解题方法：① 判断物体是否均质（均质时重心即形心）；② 用分割法把组合图形拆成若干规则图形；③ 求各部分的面积（或体积、重量）与其形心坐标；④ 代加权平均公式求整体重心；有空穴时用负面积法。
典型例题：由两个矩形组成的 T 形截面：上翼缘 100mm×20mm，腹板 20mm×80mm（下接翼缘底面）。求形心距底边的高度。 解：翼缘面积 A1=2000mm²、形心高 80+10=90mm；腹板 A2=1600mm²、形心高 40mm。yc = (2000×90+1600×40)/(2000+1600) = (180000+64000)/3600 = 244000/3600 = 67.8mm。
常见问法：形心怎么求、组合图形重心怎么算、重心在哪里
课内前置：《工程力学》第3章 平面任意力系

## EM.7.2 · 点的速度合成定理
课程：工程力学；章节：第7章 点的合成运动；证据等级：教材目录（章节结构）

【工程力学】第7章 点的合成运动 · 点的速度合成定理 · 大二
定义：绝对速度等于相对速度与牵连速度的矢量和
关键公式：va = ve + vr（绝对速度 = 牵连速度 + 相对速度）
易错点：混淆牵连点位置、动点动系选择不当导致相对轨迹复杂。
要点：对任意运动形式均成立。关键是合理选择动点与动系：动系固连于运动参考体，牵连速度是动系上与动点重合之点在该瞬时的速度。
解题方法：① 选动点与动系（动系固连于运动参考体）；② 分清绝对运动、相对运动与牵连运动；③ 牵连速度取动系上与动点重合之点的速度；④ 由 va=ve+vr 作速度平行四边形求解。
典型例题：小船在静水中以 4m/s 垂直渡河，河水以 3m/s 沿岸流动。求小船相对地面的实际速度。 解：va = √(4²+3²) = 5m/s，与岸线夹角 arctan(4/3) = 53.13°。
常见问法：船过河怎么算、相对速度怎么合、牵连速度是什么

## EM.8.3 · 用瞬心法求平面图形内各点的速度
课程：工程力学；章节：第8章 刚体的平面运动；证据等级：知识库明确关系

【工程力学】第8章 刚体的平面运动 · 用瞬心法求平面图形内各点的速度 · 大二
定义：瞬时速度中心法，是求平面运动速度最简便的方法
关键公式：v = ω·R（R 为该点到瞬心的距离，方向垂直于该点与瞬心的连线）；ω = vA / PA
易错点：瞬心位置逐瞬时变化，不能当作固定转轴。
要点：瞬心是该瞬时速度为零的点；ω≠0 时瞬心存在且唯一，ω=0（瞬时平动）时在无穷远。找法：任两点速度方向垂线的交点。
解题方法：① 作图形内任意两点速度方向的垂线，其交点为瞬心 P；② 求图形角速度 ω = vA/PA；③ 任一点速度 v = ω×该点到瞬心的距离，方向垂直于连线；④ 两点速度平行且不等时，用连线与速度矢端连线的交点定瞬心；瞬时平动则瞬心在无穷远。
典型例题：杆 AB 长 0.5m，A 端沿竖直墙下滑、B 端沿水平地面滑动。当 A 端离地 0.4m 时 vA=0.3m/s 向下，求 B 端速度与杆的角速度。 解：勾股：OB = √(0.5²−0.4²) = 0.3m。瞬心 P 在过 A 的水平线与过 B 的竖直线交点，PA = OB = 0.3m，PB = OA = 0.4m。ω = vA/PA = 0.3/0.3 = 1rad/s，vB = ω×PB = 1×0.4 = 0.4m/s（水平向右）。
常见问法：杆子运动速度怎么求、瞬心在哪里、平面运动怎么求速度
跨课程前置：《工程力学》第8章 刚体的平面运动（物理学 4-1「刚体的定轴转动」是工程力学第8章「刚体的平面运动」的直接前置）
课内前置：《工程力学》第6章 点的运动学和刚体的基本运动

## EM.10.2 · 动量定理
课程：工程力学；章节：第10章 动量定理；证据等级：知识库明确关系

【工程力学】第10章 动量定理 · 动量定理 · 大二
定义：质点系动量定理与动量守恒的判定
关键公式：微分形式：dp/dt = ΣF(e)；积分形式：m·v2 − m·v1 = ΣI(e)；质心运动定理：m·aC = ΣF(e)
易错点：内力虽不改变动量，但一般会改变动能。
要点：内力不影响动量，动量变化只取决于外力；质心运动如同质量集中于质心、受全部外力作用的质点。
解题方法：① 取研究对象（质点或质点系）；② 分析外力并求外力主矢；③ 用微分形式 dp/dt=ΣF 或积分形式 mv2−mv1=ΣI 列方程；④ 按坐标轴投影求解；⑤ 判断合外力是否为零以决定能否用动量守恒。
典型例题：质量 2kg 的物体原以 3m/s 向右运动，受恒定向左的力 5N 作用 1s。求 1s 末速度。 解：取向右为正：Δp = ΣI = −5×1 = −5kg·m/s。p1 = 2×3 = 6，p2 = 6−5 = 1kg·m/s，v2 = 1/2 = 0.5m/s（向右）。
常见问法：冲量怎么算、碰撞力怎么估、动量变化

## EM.12.3 · 动能定理
课程：工程力学；章节：第12章 动能定理；证据等级：知识库明确关系

【工程力学】第12章 动能定理 · 动能定理 · 大二
定义：质点系动能定理及机械能守恒条件的判定
关键公式：T2 − T1 = ΣW（外力功 + 内力功）；机械能守恒：T1 + V1 = T2 + V2
易错点：内力功一般不为零（如爆炸、摩擦），忽略耗散做功而误用守恒是常见错误。
要点：动能定理是标量方程，便于求速度大小。机械能守恒的条件是只有保守力做功，外力功与非保守内力功均为零。
解题方法：① 明确研究对象与始末位置；② 计算全部外力功与非保守内力功；③ 用 T2−T1=ΣW 列标量方程；④ 求速度大小；⑤ 若只有保守力做功则改用机械能守恒更简便。
典型例题：质量 2kg 的物体从静止开始受恒力 10N 作用沿光滑水平面移动 3m。求末速度。 解：W = 10×3 = 30J。由 ½mv² = 30 得 v = √(2×30/2) = √30 = 5.48m/s。
常见问法：用力求速度、做功怎么变成速度、能量法怎么用

## EM.13.4 · 拉压变形与胡克定律
课程：工程力学；章节：第13章 轴向拉伸与压缩；证据等级：教材目录（章节结构）

【工程力学】第13章 轴向拉伸与压缩 · 拉压变形与胡克定律 · 大二
定义：纵向变形与横向变形，胡克定律 σ=Eε，泊松比
关键公式：σ = E·ε；Δl = N·l/(E·A)；横向应变 ε′ = −ν·ε；剪切胡克定律 τ = G·γ；G = E/[2(1+ν)]

## EM.17.2 · 平面应力状态分析
课程：工程力学；章节：第17章 应力状态与强度理论；证据等级：教材目录（章节结构）

【工程力学】第17章 应力状态与强度理论 · 平面应力状态分析 · 大二
定义：解析法求主应力与最大切应力，以及应力圆（莫尔圆）
关键公式：σ1,2 = (σx+σy)/2 ± √[((σx−σy)/2)² + τxy²]；tan2θp = 2τxy/(σx−σy)；τmax = √[((σx−σy)/2)² + τxy²]

## EM.17.4 · 强度理论简介

【工程力学】第17章 应力状态与强度理论 · 强度理论简介 · 大二
定义：第一至第四强度理论及其相当应力与适用条件
关键公式：第一：σr1=σ1；第二：σr2=σ1−ν(σ2+σ3)；第三：σr3=σ1−σ3；第四：σr4=√{½[(σ1−σ2)²+(σ2−σ3)²+(σ3−σ1)²]}；平面应力下 σr3=√(σ²+4τ²)，σr4=√(σ²+3τ²)

典型例题：塑性材料危险点 σ1=60MPa、σ2=20MPa、σ3=−40MPa。用第三强度理论校核（许用应力 [σ]=100MPa）。 解：σr3 = σ1−σ3 = 60−(−40) = 100MPa，恰好等于 [σ]，处于临界状态。若用第四强度理论：σr4 = √{½[(60−20)²+(20+40)²+(−40−60)²]} = √{½(1600+3600+10000)} = √7600 = 87.2MPa < 100MPa，安全。
常见问法：怎么判断会不会破坏、用哪个强度理论、相当应力是什么

【工程力学】第18章 组合变形 · 拉（压）弯组合变形的强度计算 · 大二
定义：用叠加法求危险点应力并建立强度条件
关键公式：拉（压）弯组合：σ = N/A ± Mz·y/Iz（危险点叠加）；圆轴弯扭组合：σr3 = √(M²+T²)/W，σr4 = √(M²+0.75T²)/W

## EM.19.2 · 欧拉公式
课程：工程力学；章节：第19章 压杆稳定；证据等级：教材目录（章节结构）

【工程力学】第19章 压杆稳定 · 欧拉公式 · 大二
定义：两端铰支压杆的临界力公式，并推广到其他约束情况
关键公式：Fcr = π²EI/(μl)²；σcr = π²E/λ²；柔度 λ = μl/i，惯性半径 i = √(I/A)
适用条件：欧拉公式适用于线弹性、小变形的细长压杆（大柔度杆，λ ≥ λp）。
易错点：欧拉公式仅在 σcr ≤ σp 时成立；I 应取截面最小惯性矩。
要点：欧拉公式适用于线弹性、小变形的细长压杆（大柔度杆，λ ≥ λp）。长度系数 μ：两端铰支 1、一端固定一端自由 2、两端固定 0.5、一端固定一端铰支 0.7。中柔度杆用经验公式，小柔度杆按强度计算。
解题方法：① 算截面惯性矩 I 与惯性半径 i=√(I/A)，I 取最小惯性矩；② 按约束确定长度系数 μ，算柔度 λ=μl/i；③ 与大柔度界限 λp=√(π²E/σp) 比较：λ≥λp 用欧拉公式，中柔度用经验公式，小柔度按强度算；④ Fcr=π²EI/(μl)²，除以稳定安全系数得许可载荷。
典型例题：两端铰支压杆，长 2m，圆截面 d=20mm，E=200GPa。求欧拉临界力。 解：I = πd⁴/64 = π×0.02⁴/64 = 7.854×10⁻⁹m⁴。μ=1，(μl)² = 4。Fcr = π²×200×10⁹×7.854×10⁻⁹/4 = 9.8696×1570.8/4 = 3875N ≈ 3.88kN。
常见问法：细长杆什么时候压弯、临界力怎么算、压杆会不会失稳
