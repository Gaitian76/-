## CT.1.8 · 基尔霍夫定律
课程：电路；章节：第1章 电路模型和电路定律；证据等级：知识库明确关系

【电路】第1章 电路模型和电路定律 · 基尔霍夫定律 · 大二
定义：KCL：节点电流代数和为零；KVL：回路电压代数和为零
关键公式：KCL: Σi=0（独立方程 n-1 个）；KVL: Σu=0（独立方程 b-n+1 个）
适用条件：二者只由网络拓扑决定，与元件性质无关，也适用于广义节点与虚拟回路。
易错点：须先规定统一电流取向或绕行方向再代数求和。
要点：KCL 体现电荷守恒（电流连续性），KVL 体现能量守恒；二者只由网络拓扑决定，与元件性质无关，也适用于广义节点与虚拟回路。
解题方法：① 标出各支路电流的参考方向；② 对独立节点列 KCL（ΣI入=ΣI出）；③ 对独立回路列 KVL（沿绕行方向，电压降取正、电压升取负）；④ 联立求解。
典型例题：10V 电源与 R1=2Ω、R2=3Ω 串联成单回路，求电流与各电阻电压，并用 KVL 校验。 解：串联电流 I = 10/(2+3) = 2A。U1 = 2×2 = 4V，U2 = 2×3 = 6V。KVL：4+6−10 = 0，闭合。
常见问法：电流进出的关系、回路电压怎么相加、节点电流定律
跨课程前置：《电路》第1章 电路模型和电路定律（电路第1章「电流和电压的参考方向」「电功率和能量」建立在物理学「静电场」「电势」）
课内后续：《电路》第2章 电阻电路的等效变换

## CT.3.6 · 节点电压法
课程：电路；章节：第3章 电阻电路的一般分析；证据等级：知识库明确关系

【电路】第3章 电阻电路的一般分析 · 节点电压法 · 大二
定义：以节点电压为未知量，列自导、互导方程，处理无伴电压源
关键公式：G·Un = In；Gii 为自电导(正)，Gij 为互电导(负)
易错点：方程右端为流入该节点的电流源代数和；受控源先按独立源列式，再用节点电压表示控制量。
要点：以 (n-1) 个独立节点电压为待求量，对各独立节点列 KCL。含理想电压源时可用超节点法，或选电压源一端接参考点。
解题方法：① 选参考节点（接地点）；② 对 (n−1) 个独立节点列 KCL，写成自导×节点电压 − 互导×相邻节点电压 = 流入电流源代数和；③ 含无伴电压源时设辅助电流或采用超节点；④ 解方程组得节点电压，再回代求各支路量。
典型例题：两节点电路：节点①经 R1=2Ω 接 6V 电压源正极（负极接地），节点①经 R2=3Ω 接地，另有 1A 电流源从地流入节点①。求节点①电压。 解：对节点①列 KCL：(U1−6)/2 + U1/3 = 1。通分：3U1−18+2U1 = 6 → 5U1 = 24 → U1 = 4.8V。校验：流入 = (6−4.8)/2 + 1 = 0.6+1 = 1.6A，流出 = 4.8/3 = 1.6A，平衡。
常见问法：怎么列电路方程、电路方程太多怎么简化、节点法怎么用

## CT.4.1 · 叠加定理
课程：电路；章节：第4章 电路定理；证据等级：教材目录（章节结构）

【电路】第4章 电路定理 · 叠加定理 · 大二
定义：线性电路中多个独立源共同作用产生的响应等于各电源单独作用响应的代数和
关键公式：y = k1·x1 + k2·x2 + …（响应 = 各独立源单独作用结果的代数和）
适用条件：仅适用于线性电路。
易错点：功率是非线性量，不能用叠加求功率；某电源单独作用时其余独立电压源短路、独立电流源开路，而受控源与电阻必须保留。
要点：仅适用于线性电路。
解题方法：① 一次只保留一个独立源，其余电压源短路、电流源开路，受控源全部保留；② 求该源单独作用下的响应分量；③ 对每个独立源重复；④ 各分量按参考方向代数相加。注意功率不能叠加。
典型例题：某支路在 10V 电压源单独作用时电流为 0.5A，在 2A 电流源单独作用时为 0.3A（两者方向相同）。求两电源同时作用时的电流。 解：同向取同号，I = 0.5+0.3 = 0.8A。若方向相反则为 0.5−0.3 = 0.2A。
常见问法：多个电源怎么一起算、能不能分别算再相加、电源叠加
课内前置：《电路》第3章 电阻电路的一般分析

## CT.4.3 · 戴维南定理
课程：电路；章节：第4章 电路定理；证据等级：教材目录（章节结构）

【电路】第4章 电路定理 · 戴维南定理 · 大二
定义：含源线性一端口网络可等效为电压源 U_oc 与电阻 R_eq 的串联
关键公式：等效为 Uoc 串联 R0；R0 = Uoc / Isc（开短路法）
易错点：独立源置零指电压源短路、电流源开路，受控源保留；含受控源时求 R0 宜用外加电源法或开短路法；等效只对外部端口成立。
要点：任一线性含源单口网络对外电路可等效为电压源 Uoc 串联电阻 R0。
解题方法：① 断开待求支路，标出端口；② 求端口开路电压 Uoc；③ 将内部独立源置零（电压源短路、电流源开路，受控源保留），求等效电阻 R0；含受控源时用外加电源法或 R0=Uoc/Isc；④ 画等效电压源串 R0 电路，接回待求支路求解。
典型例题：含源一端口网络测得开路电压 Uoc=12V、短路电流 Isc=3A。求接入 RL=6Ω 时的电流，以及负载能获得的最大功率。 解：R0 = Uoc/Isc = 12/3 = 4Ω。接 6Ω 时 I = 12/(4+6) = 1.2A。最大功率出现在 RL = R0 = 4Ω，Pmax = Uoc²/(4R0) = 144/16 = 9W。
常见问法：复杂电路怎么化简成一个电源、求最大功率怎么做、一端口怎么等效

## CT.4.4 · 诺顿定理
课程：电路；章节：第4章 电路定理；证据等级：教材目录（章节结构）

【电路】第4章 电路定理 · 诺顿定理 · 大二
定义：含源线性一端口网络可等效为电流源 I_sc 与电阻 R_eq 的并联
关键公式：等效为 Isc 并联 R0；R0 = Uoc / Isc
易错点：Isc 方向须与端口短路电流实际方向一致；R0 仅由网络内部参数决定，与外部无关。

## CT.4.5 · 最大功率传输定理
课程：电路；章节：第4章 电路定理；证据等级：教材目录（章节结构）

【电路】第4章 电路定理 · 最大功率传输定理 · 大二
定义：负载获得最大功率的条件是 R_L=R_eq，最大功率为 U_oc²/4R_eq
关键公式：RL = R0 时取最大功率 Pmax = Uoc² / (4·R0)
易错点：此时传输效率仅 50%（内阻耗散等量功率），故多用于弱电与信号传输；电力系统追求高效率而非最大功率。
要点：正弦稳态下为共轭匹配 ZL = Z0*。
解题方法：① 求含源一端口的戴维南等效 Uoc 与 R0；② 令负载电阻 RL = R0（正弦稳态取共轭匹配 ZL = Z0*）；③ 代 Pmax = Uoc²/(4R0)。注意此条件下效率仅 50%。
典型例题：含源一端口 Uoc=10V、R0=50Ω，求负载可获得的最大功率。 解：RL = R0 = 50Ω 时 Pmax = Uoc²/(4R0) = 100/200 = 0.5W。
常见问法：负载什么时候功率最大、匹配怎么做、怎么让喇叭声音最大

【电路】第7章 一阶电路和二阶电路的时域分析 · 一阶电路的全响应 · 大二
定义：三要素法：初始值、稳态值、时间常数，可直接写出全响应
关键公式：f(t) = f(∞) + [f(0+) − f(∞)]·e^(−t/τ)；τ = R0·C 或 τ = L/R0

定义：有功功率 P、无功功率 Q、视在功率 S 与功率因数 cosφ

## CT.11.2 · RLC 串联电路的谐振
课程：电路；章节：第11章 电路的频率响应；证据等级：教材目录（章节结构）

【电路】第11章 电路的频率响应 · RLC 串联电路的谐振 · 大二
定义：谐振频率 ω₀=1/√(LC)、特性阻抗与品质因数 Q
关键公式：ω0 = 1/√(LC)，f0 = 1/(2π√(LC))；Q = ω0L/R = (1/R)√(L/C)；通频带 BW = ω0/Q = R/L

## CT.14.7 · 网络函数的极点和零点

【电路】第14章 线性动态电路的复频域分析 · 网络函数的极点和零点 · 大二
定义：由网络函数分子分母的根确定，决定电路的性质
关键公式：H(s) = R(s)/E(s) = K·∏(s−zi)/∏(s−pk)；zi 为零点，pk 为极点
