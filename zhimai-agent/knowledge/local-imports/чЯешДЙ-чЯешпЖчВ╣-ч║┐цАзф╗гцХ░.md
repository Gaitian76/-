## LA.1.3 · n 阶行列式
课程：线性代数；章节：第1章 行列式；证据等级：基于目录推断

【线性代数】第1章 行列式 · n 阶行列式 · 大一
定义：行列式的递归定义：所有取自不同行不同列的 n 个元素乘积的代数和
关键公式：D = Σ (−1)^τ(j1…jn) · a1j1·a2j2·…·anjn（共 n! 项）；按行展开：D = Σj a_ij·A_ij
易错点：展开时代数余子式符号为 (−1)^(i+j)；行列式是一个数，与矩阵（数表）有本质区别。
要点：性质：转置值不变；两行（列）互换变号；某行（列）有公因子可外提；某行（列）乘 k 加到另一行不变；两行相同或成比例则为零。
解题方法：① 优先观察是否含零较多或某行（列）成比例，可用性质先化简；② 用「某行乘 k 加到另一行」制造零元素（化三角）；③ 化为上三角行列式后取主对角线元素之积；④ 若需降阶，按含零最多的一行（列）展开，注意符号 (−1)^(i+j)。
典型例题：计算三阶行列式 D = |1 2 3; 4 5 6; 7 8 10|。 解：按第一行展开：D = 1×(5×10−6×8) − 2×(4×10−6×7) + 3×(4×8−5×7) = 1×2 − 2×(−2) + 3×(−3) = 2+4−9 = −3。
常见问法：行列式怎么算、三阶行列式怎么求、行列式有什么用
跨课程后续：《电路》第3章 电阻电路的一般分析（线性代数「行列式」中的克拉默法则可用于求解电路方程；两书目录未互相引用）

## LA.2.3 · 逆矩阵
课程：线性代数；章节：第2章 矩阵及其运算；证据等级：知识库明确关系

【线性代数】第2章 矩阵及其运算 · 逆矩阵 · 大一
定义：方阵可逆的充要条件是行列式不为零，并用伴随矩阵求逆
关键公式：A·A* = A*·A = |A|E；|A| ≠ 0 时 A⁻¹ = A*/|A|；|A⁻¹| = 1/|A|
易错点：A* 的第 i 行第 j 列元素是 A_ji（转置排列）；A 不可逆时 A* 仍可能存在，但不满足求逆公式。
要点：伴随矩阵由各元素的代数余子式转置排列构成。 (AB)⁻¹ = B⁻¹A⁻¹。
解题方法：① 先算 |A|，为 0 则不可逆；② 求各元素的代数余子式并转置得伴随矩阵 A*；③ A⁻¹ = A*/|A|；④ 阶数较高时改用初等行变换法 [A|E] → [E|A⁻¹]；⑤ 用 A·A⁻¹=E 校验。
典型例题：求 A = [[1,2],[3,4]] 的逆矩阵。 解：|A| = 1×4−2×3 = −2。A* = [[4,−2],[−3,1]]。A⁻¹ = A*/(−2) = [[−2,1],[1.5,−0.5]]。校验：A·A⁻¹ = E ✓
常见问法：矩阵怎么求逆、矩阵能不能相除、可逆条件是什么
跨课程后续：《电路》第15章 电路方程的矩阵形式（线性代数「矩阵及其运算」（含逆矩阵、矩阵分块法）是电路第15章「电路方程的矩阵形）

## LA.2.4 · 克拉默法则
课程：线性代数；章节：第2章 矩阵及其运算；证据等级：知识库明确关系

【线性代数】第2章 矩阵及其运算 · 克拉默法则 · 大一
定义：用行列式表示 n 元线性方程组的解，并给出有唯一解的条件
关键公式：Ax = b，若 |A| ≠ 0，则 x_j = |A_j|/|A|（A_j 是把 A 的第 j 列换成常数列 b 所得的矩阵）
适用条件：方程个数等于未知数个数，且系数行列式不为零，此时解存在且唯一。推论：齐次方程组 |A|≠0 只有零解，有非零解必 |A|=0。
易错点：|A|=0 时公式失效，须改用矩阵的秩判定。
解题方法：① 确认方程个数等于未知数个数；② 算系数行列式 |A|，若 |A|≠0 才能用；③ 逐个把第 j 列换成常数列 b，算 |Aj|；④ xj = |Aj|/|A|；⑤ |A|=0 时改用秩判定。
典型例题：解方程组 2x+3y=8，x−2y=−3。 解：|A| = 2×(−2)−3×1 = −7 ≠ 0。|A1| = 8×(−2)−3×(−3) = −16+9 = −7，x = 1；|A2| = 2×(−3)−8×1 = −14，y = 2。解为 x=1，y=2。
常见问法：用行列式解方程组、方程组怎么用公式解
跨课程后续：《电路》第15章 电路方程的矩阵形式（线性代数「矩阵及其运算」（含逆矩阵、矩阵分块法）是电路第15章「电路方程的矩阵形）

## LA.3.3 · 线性方程组的解
课程：线性代数；章节：第3章 矩阵的初等变换与线性方程组；证据等级：知识库明确关系

【线性代数】第3章 矩阵的初等变换与线性方程组 · 线性方程组的解 · 大一
定义：用系数矩阵与增广矩阵的秩判定无解、有唯一解或有无穷多解
关键公式：Ax=b：r(A)=r(A,b)=n 有唯一解；r(A)=r(A,b)<n 有无穷多解；r(A)<r(A,b) 无解。Ax=0：r(A)=n 只有零解；r(A)<n 有非零解，自由未知量 n−r(A) 个
易错点：区分齐次与非齐次结论；初等变换不改变秩，但会改变行列式的值。
要点：判定关键是比较系数矩阵的秩 r(A) 与增广矩阵的秩 r(A,b)。方法：初等行变换化阶梯形后比较秩。
解题方法：① 写出系数矩阵 A 与增广矩阵 (A,b)；② 初等行变换化行阶梯形，比较 r(A) 与 r(A,b)；③ r(A)<r(A,b) 无解；r(A)=r(A,b)=n 唯一解；r(A)=r(A,b)<n 无穷多解，自由未知量 n−r(A) 个；④ 有解时回代求通解。
典型例题：判定方程组 x+y+z=1，2x+2y+2z=2 的解的情况。 解：第二式是第三式的 2 倍，故 r(A)=r(A,b)=1 < 3 = n，有无穷多解，自由未知量 3−1 = 2 个。令 y=s、z=t，则 x = 1−s−t。
常见问法：方程组有没有解、无穷多解怎么表示、秩是什么
跨课程后续：《电路》第3章 电阻电路的一般分析（线性代数「线性方程组的解」对应电路第3章支路电流法、网孔电流法、节点电压法的求解）

## LA.4.2 · 向量组的线性相关性
课程：线性代数；章节：第4章 向量组的线性相关性；证据等级：教材目录（章节结构）

【线性代数】第4章 向量组的线性相关性 · 向量组的线性相关性 · 大一
定义：线性相关与线性无关的定义、判定定理与基本性质
关键公式：线性相关 ⇔ 存在不全为零的 k1,…,km 使 k1α1+…+kmαm = 0；以向量为列构成矩阵 A，则 r(A)<m 相关、r(A)=m 无关
易错点：部分无关不等于整体无关。
要点：线性无关指只有全零组合才等于零向量；线性相关则至少有一个向量可由其余向量线性表示。 含零向量必相关；m 个 n 维向量当 m>n 时必相关。
解题方法：① 把向量作为列构成矩阵 A；② 求 r(A)；③ r(A) 等于向量个数则线性无关，小于则线性相关；④ 相关时说明至少一个向量可由其余线性表示，并可求最大无关组。
典型例题：判断 α1=(1,2,3)、α2=(2,4,6) 的线性相关性。 解：α2 = 2α1，存在不全为零的系数 2 与 −1 使 2α1−α2=0，故线性相关。矩阵秩 r = 1 < 2 亦印证。
常见问法：向量相关是什么意思、怎么判断线性相关、能不能互相表示

## LA.5.2 · 方阵的特征值与特征向量
课程：线性代数；章节：第5章 相似矩阵及二次型；证据等级：基于目录推断

【线性代数】第5章 相似矩阵及二次型 · 方阵的特征值与特征向量 · 大一
定义：特征方程 |A-λE|=0，特征值与特征向量的求法及基本性质
关键公式：A x = λ x（x ≠ 0）；λ 为特征方程 |λE − A| = 0 的根；Σλi = tr(A)，Πλi = |A|
易错点：特征向量必须非零；不同特征值对应的特征向量线性无关。
要点：属于同一特征值的全部特征向量构成特征子空间（不含零向量）。 特征值之和等于迹、之积等于行列式。
解题方法：① 写特征方程 |λE−A|=0 并解特征多项式得全部特征值；② 对每个 λ 解齐次方程组 (λE−A)x=0，其基础解系即特征向量；③ 用 Σλ=tr(A)、Πλ=|A| 校验；④ 需要时对特征向量作施密特正交化并单位化。
典型例题：求 A = [[2,1],[1,2]] 的特征值与特征向量。 解：|λE−A| = (λ−2)²−1 = λ²−4λ+3 = 0 → λ=1 或 3。λ=1 时解得 (1,−1)ᵗ；λ=3 时解得 (1,1)ᵗ。校验：λ1+λ2 = 4 = 迹，λ1λ2 = 3 = |A| ✓
常见问法：特征值怎么算、特征向量是什么、特征值有什么用

## LA.5.3 · 相似矩阵
课程：线性代数；章节：第5章 相似矩阵及二次型；证据等级：基于目录推断

【线性代数】第5章 相似矩阵及二次型 · 相似矩阵 · 大一
定义：相似矩阵有相同的特征值，以及方阵可对角化的条件
关键公式：P⁻¹AP = B；A 可对角化 ⇔ A 有 n 个线性无关的特征向量 ⇔ 每个特征值的几何重数 = 代数重数
易错点：特征值有重根不一定不可对角化，须比较几何重数与代数重数。
要点：相似矩阵有相同的特征值、迹、行列式与秩。可对角化的充分条件：有 n 个互异特征值，或 A 为实对称矩阵（此时 P 的列为特征向量，对角元为相应特征值）。
解题方法：① 求全部特征值；② 对每个特征值求特征向量的个数（几何重数）；③ 几何重数等于代数重数则 A 可对角化；④ 以特征向量为列组成 P，则 P⁻¹AP=Λ。
典型例题：A = [[2,1],[1,2]] 是否可对角化？若可，写出 P 与 Λ。 解：两特征值 1、3 互异，各有 1 个线性无关特征向量，故可对角化。P = [[1,1],[−1,1]]，Λ = diag(1,3)，满足 P⁻¹AP = Λ。
常见问法：矩阵能不能变成对角阵、可对角化条件、相似是什么

## LA.5.4 · 对称矩阵的对角化
课程：线性代数；章节：第5章 相似矩阵及二次型；证据等级：基于目录推断

【线性代数】第5章 相似矩阵及二次型 · 对称矩阵的对角化 · 大一
定义：实对称矩阵的特征值全为实数，必可用正交矩阵对角化
关键公式：实对称矩阵 A 存在正交矩阵 Q 使 Q⁻¹AQ = QᵀAQ = Λ = diag(λ1,…,λn)
要点：实对称矩阵的特征值全为实数，不同特征值的特征向量相互正交，故必可正交对角化。步骤：求特征值 → 求特征向量 → 同一特征值内多个向量施密特正交化 → 单位化 → 组成正交矩阵 Q。
解题方法：① 求特征值与特征向量；② 对同一特征值的多个特征向量作施密特正交化；③ 全部单位化得正交矩阵 Q；④ 则 QᵀAQ = diag(λ1,…,λn)。
典型例题：把 A = [[1,2],[2,1]] 正交对角化。 解：特征值 λ=3、−1。λ=3 的单位特征向量 (1/√2, 1/√2)ᵗ；λ=−1 的单位特征向量 (1/√2, −1/√2)ᵗ。Q = (1/√2)[[1,1],[1,−1]]，QᵀAQ = diag(3,−1)。
常见问法：对称矩阵怎么对角化、正交变换怎么做

## LA.5.5 · 二次型及其标准形
课程：线性代数；章节：第5章 相似矩阵及二次型；证据等级：基于目录推断

【线性代数】第5章 相似矩阵及二次型 · 二次型及其标准形 · 大一
定义：用正交变换把二次型化为只含平方项的标准形
关键公式：f(x) = xᵀAx（A 对称）经非退化线性替换 x = Cy 化为 f = d1y1² + … + dnyn²；规范形系数为 ±1、0
要点：惯性定理：标准形虽不唯一（系数可变），但正惯性指数 p、负惯性指数 q 与秩 r = p+q 是二次型的不变量。 合同变换保持秩与惯性指数；用正交变换得到的标准形系数即特征值。
解题方法：① 写出对称矩阵 A（注意交叉项系数要除以 2）；② 求 A 的特征值；③ 作正交变换 x=Qy，标准形为 λ1y1²+…+λnyn²；④ 由正负特征值个数读惯性指数；⑤ 也可用配方法化标准形。
典型例题：用正交变换把 f = 2x1²+2x2²+2x1x2 化为标准形。 解：A = [[2,1],[1,2]]，特征值 1、3。作正交变换后 f = y1²+3y2²，正惯性指数 p=2，秩 r=2。
常见问法：二次型怎么化简、配方法怎么用、标准形是什么

## LA.5.7 · 正定二次型
课程：线性代数；章节：第5章 相似矩阵及二次型；证据等级：基于目录推断

【线性代数】第5章 相似矩阵及二次型 · 正定二次型 · 大一
定义：正定性的判定：特征值全正或各阶顺序主子式全大于零
关键公式：f(x)=xᵀAx 正定 ⇔ 任意 x≠0 有 f(x)>0 ⇔ A 的特征值全正 ⇔ 各阶顺序主子式全大于零 ⇔ 正惯性指数 p = n
易错点：只有对称矩阵才谈正定；注意顺序主子式与一般主子式的区别。
要点：正定只针对实对称矩阵（二次型），判定前须先确认矩阵对称。常用判据是全部顺序主子式大于零。
解题方法：① 确认矩阵对称；② 依次计算各阶顺序主子式，全大于零即正定；③ 或求特征值，全正即正定；④ 或看正惯性指数是否等于 n。
典型例题：判断 A = [[2,−1],[−1,2]] 是否正定。 解：一阶顺序主子式 2>0；二阶 det A = 4−1 = 3>0。全部顺序主子式大于零，故正定。特征值为 1 和 3，也全为正，两者一致。
常见问法：怎么判断正定、二次型是不是正的、正定有什么用
