## 可直接使用的知识

文件格式按用途选择：CSV 便于交换但体积大且类型弱；二进制紧凑快速但必须保存格式版本；TDMS 适合分通道记录测量数据和属性。

可靠写入流程：创建/打开 → 写文件头或元数据 → 分块追加数据 → flush 或周期落盘 → 关闭引用。循环内每次打开关闭文件会显著降低性能；长时间采集也不能无限缓存到内存。

必须记录采样率、单位、通道名、量程、标定系数、设备编号、软件版本和时间戳，否则数据难以复现。文件名中可包含任务和起始时间，但不要仅靠文件名保存全部元数据。

异常停机可能造成尾部不完整。读取程序应校验版本、记录长度和通道数，并能忽略损坏尾块或报告明确错误。

## 可复现实验：TDMS 双通道采集文件

本节是依据 NI TDMS 文档整理的独立练习，对应教材第 6 章文件 I/O 主题。先用仿真数据，不依赖采集卡。

1. 设两路信号为 `温度` 与 `振动`，各生成 1,000 个样本。采样间隔分别记录为 `dt=0.1 s` 与 `dt=0.001 s`；不同采样率不要合并成一个无说明的数值数组。
2. 用 `TDMS Open → TDMS Set Properties → TDMS Write → TDMS Close` 建立文件。给两路数据使用明确的 group/channel 名称，例如 `实验1/温度`、`实验1/振动`，并在相应级别写入单位、采样间隔、开始时间、传感器编号等属性。TDMS 结构为文件、组、通道三级。
3. 用 `TDMS Open → TDMS Read/TDMS Get Properties → TDMS Close` 回读。验收条件：两个通道各 1,000 点；第一个和最后一个样本与写入值一致；单位和时间信息仍可读出。若连续写入，文件引用放在循环外；`TDMS Flush` 可用于阶段性落盘，但会增加写入开销。
4. 故障测试：路径不存在、文件只读、空数组、运行中断后重新打开。把路径和 NI 错误码一起记录，确认错误路径也能关闭引用。

**来源**：[NI：Introduction to LabVIEW TDM Streaming VIs](https://www.ni.com/en/support/documentation/supplemental/06/introduction-to-labview-tdm-streaming-vis.html)、[NI：TDMS Write Function](https://www.ni.com/docs/en-US/bundle/labview-api-ref/page/functions/tdms-write.html)、[清华大学出版社：本书目录](https://www.tup.tsinghua.edu.cn/bookscenter/bookcatalog?id=07683001)。函数接口以 LabVIEW 2017 安装帮助核对；链接中的在线文档可能随版本更新。
