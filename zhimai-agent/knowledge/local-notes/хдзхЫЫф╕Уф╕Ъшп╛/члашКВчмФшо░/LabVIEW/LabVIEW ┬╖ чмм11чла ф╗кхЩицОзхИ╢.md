## 可直接使用的知识

VISA 为串口、USB、GPIB、TCP/IP 等接口提供统一访问。典型流程是 Open → 配置超时/终止符 → Write 命令 → Read 响应 → 检查错误 → Close。

许多仪器使用 SCPI。查询命令通常以问号结尾，例如测量查询；具体命令必须以仪器编程手册为准。串口通信还需双方一致的波特率、数据位、校验、停止位与终止符。

不要用固定延时猜测仪器何时完成。优先读取状态寄存器、操作完成查询或使用超时轮询。二进制块数据要按协议解析长度头和字节序。

排错顺序：在厂商工具/MAX 中确认资源 → 用终端发送最小命令 → 检查终止符和超时 → 再接入完整 VI。所有引用必须在错误路径上也能关闭。

## 可复现实验：先验证 VISA 消息边界

对应本书第 11 章的 VISA、串口与 USB 仪器控制目录；具体命令来自设备厂商编程手册，以下实验不预设所有仪器都支持同一命令。

1. 在 NI MAX 找到 VISA 资源名称并打开交互测试。查设备手册确认接口、波特率、数据位、校验位、停止位、超时、命令结束符及响应结束条件，再用一条只读查询命令验证往返。若设备支持 SCPI，常见识别查询是 `*IDN?`；非 SCPI 设备必须改用其专有命令。
2. LabVIEW 中按 `VISA Open/Configure Serial Port → VISA Write → VISA Read → VISA Close` 接线，错误线贯穿所有节点。ASCII 响应用手册规定的 LF、CR 或 CRLF 结束；`VISA Read` 的字节数给合理上限，并用终止符或明确长度结束，不以循环运行时间猜测报文完整性。
3. 对二进制数据禁用串口终止符读取，按协议先解析长度、再读足够字节；否则数据中某个 `0x0A` 可能被错当结束。把原始字节和解析后数值分别保存，核对字节序、单位和校验位。
4. 测试错误资源名、错误波特率、拔线与超时；无论哪条路径都关闭会话。不要把连续查询塞进前面板事件分支，避免 UI 阻塞。

**来源**：[NI：Termination Characters in NI-VISA](https://www.ni.com/en/support/documentation/supplemental/06/termination-characters-in-ni-visa.html)、[NI：VISA Configure Serial Port](https://www.ni.com/docs/sw-UG/bundle/labview-api-ref/page/vi-lib/instr/visa-llb/visa-configure-serial-port-instr-vi.html)、[清华大学出版社：本书目录](https://www.tup.tsinghua.edu.cn/bookscenter/bookcatalog?id=07683001)。NI 页面提供通信机制；仪器命令须以具体机型手册为准。
