## 可直接使用的知识

声卡通常是交流耦合音频设备，常见采样率 44.1 kHz 或 48 kHz，只适合其模拟前端允许的音频频段；不能可靠测量直流和超低频，也不能直接接工业电压。

输入电压应经过隔离、限幅和衰减，严禁把未知高压直接接入麦克风/线路输入。声卡读数通常以相对满量程表示，若要得到帕、伏等物理量，必须用已知信号或校准器求比例系数。

有限采集适合一次性记录；连续采集要处理环形缓冲、块长度和停止逻辑。录放同时进行时可能存在不同的时钟、缓冲延迟和采样率转换，测相位或传递函数前要校准延时。

声卡适合教学、语音和低成本振动演示；需要同步、绝对精度、隔离或 ICP/IEPE 供电时应使用专用采集硬件。

## 课堂补充

## 可验证练习：录制并回读 1 秒音频

使用已确认可用的电脑麦克风和 LabVIEW Sound VIs：`Sound Input Configure → Sound Input Start → Sound Input Read → Sound Input Stop → Sound Input Clear`。选择设备支持的采样率，例如 `48,000 samples/s`，设一声道，采集约 1 秒并记录实际样本数、波形峰值及是否削顶；期望样本数约 48,000，具体以驱动实际返回为准。再用同样的样本率进行频谱观察，比较安静环境与轻拍桌面的差异。错误测试可选择不存在的音频设备或被其他程序独占的设备，确认仍执行 Clear。若要播放，另用 `Sound Output Configure/Write/Clear` 并降低输出音量。

音频设备的任务 ID、配置和释放流程来自 [NI：Using Sound Input and Sound Output Devices](https://www.ni.com/docs/en-US/bundle/labview/page/using-sound-input-and-sound-output-devices.html)及[NI：Sound Input Stop VI](https://www.ni.com/docs/en-US/bundle/labview-api-ref/page/vi-lib/sound2/lvsound2-llb/sound-input-stop-vi.html)；章节主题由[出版社目录](https://www.tup.tsinghua.edu.cn/bookscenter/bookcatalog?id=07683001)核对。声卡默认数据不具备物理量标定，不将波形数值直接称为伏特或帕。
