## 可直接使用的知识

工业机器人不是单机，而是“机器人本体 + 控制器 + 末端工具 + 外部轴/工装 + 传感器 + 安全系统”的工作站。危险主要来自高速运动、夹持/焊接能量、重力下落、误启动和人员进入运动包络。

### 安全控制的基本层级

1. **本质安全设计**：限制运动范围，消除锐边和坠落风险。
2. **工程防护**：围栏、安全门、光栅、安全 PLC、急停与安全速度监控。
3. **管理措施**：权限、点检、作业许可、上锁挂牌（LOTO）和培训。
4. **个人防护**：最后一道防线，不能替代工程防护。

示教前的实用检查顺序是：确认人员和障碍物 → 检查工具与工件固定 → 选择示教模式 → 保持低速倍率 → 握持使能开关 → 单步/短距离移动 → 随时准备释放使能或急停。急停只用于紧急状态，不应当作正常停机按钮。

> [!warning] 安全边界
> T1、T2、AUTO 的允许速度和行为受控制器、地区标准及系统集成配置影响。任何实机操作都以实验室规程、风险评估和该控制器安全手册为准。

### 读懂安全功能：普通工作范围与 DCS 保护区

在一张工作站俯视图上分别画出机器人**机械可达范围**、正常工艺路径和人员可能进入的区域。然后标出需要安全监控的位置与速度限制。FANUC 官方说明：DCS Basic Position Check 监控预设位置界限，Position and Speed Check 还可监控速度；超出已配置限制会切断电机动力。由此可知，普通 TP 程序中的 `IF` 条件或 ROBOGUIDE 的可视化范围，不能代替经过验证的安全功能。

课堂练习只需解释这三种边界各解决什么问题，并核对现场是否装有相应 DCS 选项；安全区的实际配置与验证须由授权人员依据风险评估和具体设备手册执行。不要仅因仿真显示“无碰撞”就推断人员可进入工作区。

**来源**：[FANUC Dual Check Safety 官方说明](https://www.fanucamerica.com/products/software/robot/fanuc-dual-check-safety-dcs)。
