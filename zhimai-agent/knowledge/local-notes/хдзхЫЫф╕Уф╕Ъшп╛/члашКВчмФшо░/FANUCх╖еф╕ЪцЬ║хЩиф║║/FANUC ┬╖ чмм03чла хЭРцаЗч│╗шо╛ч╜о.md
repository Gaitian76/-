## 可直接使用的知识

工具坐标系描述 TCP 相对机器人法兰的位置与姿态；用户坐标系描述工件/工作台相对机器人基座的位置与姿态。程序点位只有在正确的工具号和用户坐标系下才具有可重复的几何意义。

坐标变换可写成齐次变换链：

$$ ^B T_P = {^B T_U}\,{^U T_P} $$

工具参与路径计算时还要考虑法兰到 TCP 的变换。工具定义错误会导致绕点旋转时 TCP 漂移；用户坐标系错误会使整条工件轨迹整体平移或旋转。

### 标定与验证

- 三点法主要求 TCP 位置：用不同姿态让同一 TCP 接触同一固定点。
- 六点法在此基础上确定工具方向。
- 用户坐标系三点法通常用原点、X 正方向点、XY 平面点确定坐标系。
- 验证 TCP：保持 TCP 对准固定尖点改变姿态，尖点应基本不动。
- 验证用户坐标系：沿 User X/Y 点动，应与工件对应边平行；沿 Z 点动应垂直工作面。

误差来源包括接触点重复性差、工具松动、三点分布过近、姿态变化不足以及误选工具号/用户坐标系。

### 最小验证：TCP 与工件基准

1. 在仿真中固定一个可见尖点，使用同一 TCP、不同法兰姿态触及它，记录各次 TCP 与尖点的偏差；三次姿态应有明显差异。若误差大，重查接触点、工具安装与 UTOOL 编号。FANUC 官方的三点法演示正是以固定参照点和改变姿态来确定 TCP。
2. 在夹具上选择可重复接触的原点、X 正方向点与 XY 平面点；建立用户坐标系后，切换到该 User 点动，检验 X/Y 与工件边平行。每个示教点记下对应 UFRAME 和 UTOOL 编号，不只记笛卡尔数值。
3. 复制一套虚拟夹具并平移，重新示教夹具基准，再比较原程序轨迹是否随工件移动。FANUC 的公开教学强调，程序点记录在所选用户坐标系下；改变夹具位置后，正确重教该基准可恢复相对路径，但仍须核验可达性与干涉。

**注意**：这是一套根据官方公开教学设计的练习，并非本教材的原题；三点法/六点法具体界面和精度公差应以课程设备为准。
