## 可直接使用的知识

I/O 是机器人与 PLC、夹具和安全系统之间的握手接口。普通数字 I/O 用于工艺逻辑，安全信号必须走经认证的安全回路，不能用普通程序逻辑替代。

### 典型握手

1. PLC 给出“允许启动”和任务号。
2. 机器人确认条件满足并返回“就绪”。
3. PLC 发启动脉冲。
4. 机器人返回“运行中”。
5. 程序结束后返回“完成”，PLC 撤销任务。
6. 任一步超时或条件丢失，进入故障状态。

UOP 是外部控制机器人状态与启动的接口集合。RSR 常用于固定编号程序的远程启动；PNS 常通过选择编号再触发生产启动。具体信号名、极性和时序随控制器配置而异。

排错先看三层：物理层（接线、电压、公共端）→ 映射层（机架/插槽/起始点）→ 逻辑层（极性、互锁、脉冲宽度和超时）。每个输出都应能在图纸中找到去向，每个输入都应有明确产生条件。

### UOP 与生产启动方式

普通 DI/DO 面向夹具、传感器等工艺信号；UOP（User Operator Panel）是一组供外部设备控制机器人状态和程序启动的系统接口。FANUC 的公开教学分别介绍 OTHER（外部启动一个 MAIN 程序）、PNS（由外部选择程序编号）和 RSR（由外部请求对应程序）的方案。它们的信号配置、程序选择模式和启动逻辑不同；设计 PLC 握手表时必须先写明本单元采用哪一种，不能把三者的时序混用。

| 检查项 | 仿真可验证的证据 |
| --- | --- |
| 程序选择 | PLC 任务号与控制器显示的目标程序一致；非法编号不会启动 |
| 启动许可 | 任一工艺互锁未满足时不进入运动程序 |
| 执行反馈 | 启动、运行、完成与故障状态可由 PLC 分辨；状态复位条件写清楚 |
| I/O 测试模式 | 强制或模拟的信号在退出调试前清除并复核 |

FANUC 官方 I/O 仿真教学指出，模拟输入可用于没有实物的调试，模拟输出不会驱动实际设备；它也提醒生产时要防止模拟状态遗留。上述握手表是工程练习，不是厂家规定的固定 UOP 地址表。实际地址、极性、持续时间及安全回路由具体控制器和 PLC 项目共同决定。
