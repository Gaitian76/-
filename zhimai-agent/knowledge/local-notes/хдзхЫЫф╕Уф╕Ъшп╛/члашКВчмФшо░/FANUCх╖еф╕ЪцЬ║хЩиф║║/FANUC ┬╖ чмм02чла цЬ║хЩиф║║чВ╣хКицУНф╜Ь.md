## 可直接使用的知识

点动的本质是选择“运动坐标系 + 运动方向 + 速度倍率”，再由控制器把命令换算为各关节运动。

### 常用点动方式

| 方式 | 控制对象 | 适合场景 |
| --- | --- | --- |
| Joint | J1–J6 各关节 | 脱离奇异点、避障、粗定位 |
| World | 基坐标系 X/Y/Z 与姿态 | 按工作站固定方向移动 |
| Tool | 工具坐标系方向 | 沿焊枪、夹爪或探针轴线进退 |
| User | 用户坐标系方向 | 沿工作台、托盘或工件方向移动 |

位置通常可用关节角表示，也可用笛卡尔位姿 $(x,y,z,w,p,r)$ 表示。笛卡尔点动接近腕部奇异点或工作空间边界时，关节速度可能突然增大；这时应降低倍率、改用 Joint 点动并重新规划姿态。

实用步骤：确认当前坐标系与工具号 → 查看位置画面 → 低速点动单轴/单方向 → 接近目标前进一步降速 → 记录位置 → 用反向小位移验证方向。

### 可复现实验：判断当前点动坐标系

在教师许可的空载仿真工作站中，把同一 TCP 放在可观察的位置，先选 Joint，逐一轻点 J1、J2，记录“哪个关节转了”；再选 World，轻点 X/Y，记录 TCP 相对机器人基座的移动；最后切换已标定的 User，轻点 X/Y，检查移动方向是否与工件边平行。每次只改变一个因素，保存选用的坐标系、UTOOL/UFRAME 编号和位置截图。若方向与预期不符，先停下核对坐标系号与轴向，不通过重复试点“碰运气”。

FANUC 的公开 CRX 教学页确认了点动前启用示教器、在示教中保持使能开关、用 Joint 和 Cartesian 模式观察不同运动的基本逻辑；CRX 的平板界面与本课程可能使用的传统示教器界面不同，因此仅借用运动原理，不套用按钮位置。用户坐标系点动相对于工件的说明见 FANUC 用户坐标系教学页。实机的模式、速度和使能条件仍以现场型号的操作手册与实验室规程为准。
