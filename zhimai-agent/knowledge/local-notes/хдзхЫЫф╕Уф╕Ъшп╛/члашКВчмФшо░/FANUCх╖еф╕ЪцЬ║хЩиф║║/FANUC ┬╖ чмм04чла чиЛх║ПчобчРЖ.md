## 可直接使用的知识

TP 程序由运动指令、逻辑指令和位置数据组成。管理程序时最重要的不是“能运行”，而是版本可追溯、入口明确、位置数据不会被误改。

### 推荐结构

- 主程序负责初始化、状态检查、循环和异常出口。
- 子程序分别负责取料、放料、回安全位、夹具动作等单一职责。
- 位置寄存器用于可变位置；普通示教点用于固定工艺点。
- 程序名、注释、工具号、用户坐标系和有效载荷必须一起记录。

调试顺序：语法检查 → 单步执行 → 空载低速 → 带工具低速 → 带工件低速 → 连续运行。修改点位前先确认光标所在行、当前坐标系和使用该位置的所有路径。

备份至少包含控制器完整备份、程序文件和关键参数记录。复制程序后要检查点位是独立复制还是仍引用公共寄存器，避免改一处影响多条路径。

### 程序变更的可回退记录

在 ROBOGUIDE 的练习程序中，先导出基线备份，记下机器人型号、控制器软件版本、程序名、修改时间与程序点数；再仅改一处运动速度或注释，保存新版本，比较差异并运行单步测试。FANUC 官方介绍了通过示教器备份文件再载入 PalletPRO 的工作流；也指出 TP 程序导出为可读 LS 文本并重新加载需要 **ASCII Program Loader R796** 选项。没有该选项时，不应把“文本编辑后直接加载 LS”写成通用能力。

程序管理的验收物是“备份文件 + 变更说明 + 回退方法 + 试运行结果”。特别核对所修改的点位是否仍引用预期的 UTOOL/UFRAME；程序文件可回退不代表工具、用户坐标系和 I/O 设置自动随之回退。

**来源**：[FANUC PalletPRO 文件上传下载说明](https://techtransfer.fanucamerica.com/tech-transfer/palletpro-upload-and-download-files)；[FANUC TP/LS 编辑说明](https://techtransfer.fanucamerica.com/tech-transfer/how-to-edit-tp-programs-in-a-text-editor-with-ls-files)。
