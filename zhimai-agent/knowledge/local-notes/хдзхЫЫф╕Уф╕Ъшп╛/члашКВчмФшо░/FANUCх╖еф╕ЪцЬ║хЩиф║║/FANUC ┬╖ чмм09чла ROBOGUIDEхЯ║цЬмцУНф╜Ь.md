## 可直接使用的知识

抓放、输送和轨迹仿真都应采用“安全位 → 接近位 → 工艺位 → 退出位”的路径结构。这样便于调速、改点和恢复。

### 三类案例的验证重点

- 抓取/摆放：TCP、抓具开合时序、工件附着/释放、姿态和碰撞。
- 输送机：工件坐标随时间变化、到位传感器、节拍同步和错过窗口。
- 轨迹：路径连续性、CNT 转角误差、速度变化和工具姿态。
- HOME 姿态：应可达、无碰撞，并能作为异常恢复的中间状态，而不是仅仅“关节都为零”。

仿真调试按“单设备 → 单动作 → 单循环 → 连续循环”逐级进行。出现碰撞时先判断是模型定位错、TCP/坐标系错、路径点错，还是转角连续造成的扫掠体扩大。

### 从零建立抓放工作站（仿真练习）

1. 创建 Workcell 时记录 ROBOGUIDE 版本、机器人型号、控制器软件版本和工艺包；按本课程设备选型，不用默认机型代替。
2. 放置夹具、工件、托盘和末端工具；核对 CAD 模型的尺寸单位、基准点和与机器人基座的相对位置。
3. 设定 TCP 与工件用户坐标系，然后示教安全位、取件接近位、取件位、放件接近位、放件位；空载检查工作空间及关节极限。
4. 编写单循环：到取件位 → 夹具模拟反馈 → 抬升 → 到放件位 → 释放 → 返回安全位；逐段观察工件是否正确附着/脱离，检查模型干涉。
5. 在同一模型里记录周期、运动路径、负载设定及关键姿态；只更改一个参数再比较。官方 V9.1 入门教程明确涵盖建 Workcell、夹具、零件、抓放程序和节拍/负载检查，V10 教程则展示创建向导、工件附着与循环程序。两代界面不同，应依据已装版本找对应菜单。

ROBOGUIDE 官方产品页将其定位为离线编程和三维工作站仿真工具；虚拟模型的干涉检查与节拍估计只能反映已正确建模的条件，转到实体设备前仍要做现场校准和低速验证。
