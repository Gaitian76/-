## 可直接使用的知识

油液监测同时观察润滑剂状态、污染和设备磨损。常用指标包括黏度、水分、酸值、颗粒计数、元素光谱和铁磁磨粒；单项指标不能覆盖全部失效模式。

颗粒数量反映清洁度，磨粒尺寸、形貌和成分可提示磨损机制与材料来源。元素浓度上升可能来自持续磨损，也可能受补油、换油和过滤影响，因此要结合油品运行时间与设备工况看趋势。

规范取样比实验室精度更重要：固定取样点、设备状态、冲洗量和容器洁净度，避免从油箱底部偶然沉积物处随意取样。样品必须记录设备、油品、运行小时、补油/换油和过滤事件。

异常处理流程是复核样品 → 排除取样污染 → 与振动/温度/压力交叉验证 → 检查过滤与润滑系统 → 安排检修。维修后重新建立基线。

## 实操卡：让两次油样可比较

> [!info] 来源边界
> 以下整理自 SKF 润滑管理资料，适用于课程练习，不是本论文集油液篇的逐篇摘要。

| 取样前后 | 必须固定或记录 |
| --- | --- |
| 取样位置 | 优先在循环系统适当位置设置固定取样阀；避免随意从油箱底部沉积层取样。需要区分“系统清洁度”与“某支路磨粒来源”时，取样位置可能不同。 |
| 阀与容器 | 按既定程序冲洗取样阀、使用洁净容器，防止外来颗粒进入样本。 |
| 工况 | 设备运行/停机状态、油温、运行小时、补油/换油/过滤器更换时间。 |
| 检测组合 | 黏度、水分、氧化、按粒径的颗粒分布及颗粒形貌；按设备/油品选择其他指标。 |
| 解释 | 与同油品新油和本机历史基线比较；异常先复取，不能由一瓶样品断言轴承损坏。 |

例如某次颗粒数突然升高，同时黏度和水分基本稳定：先检查取样阀/瓶污染、过滤器旁通和近期检修，再复取样；若相同工况下复样仍异常，并伴随轴承包络指标上升，才提高“真实磨损或污染”的置信度。这里是**推理范例**，不是实际测得结果。SKF [润滑管理资料](https://kc.promo.skf.com/acton/ct/31734/p-0036/Bct/-/-/ct5_0/1/d?sid=TV2%3A5r8YEQjNd)明确要求样本具有代表性、阀和容器冲洗，并列出黏度、氧化、粒径分布、磨粒形貌、水及添加剂等指标。
