## 可直接使用的知识

HALCON 程序由算子组成。数据大体分为图像/区域/XLD 等图标对象和数值、字符串、句柄等控制变量（tuple）。图标对象可包含多个对象，索引和对象数量必须明确。

HDevelop 适合交互式开发：先采图和可视化，再逐步加入 ROI、预处理、分割、测量和结果输出。每一步都检查中间对象，比一次写完整流程更容易定位问题。

HALCON 区域与图像域不同。Reduce Domain 只限制后续算子的处理域，不等于裁剪并改变坐标；Crop Domain 会生成较小图像并改变尺寸/坐标处理方式。混淆两者会导致坐标映射错误。

工程程序应固定图像源、记录算子参数、处理无目标/多目标情况，并对空对象、异常句柄和相机断线设置明确分支。

## 课堂补充

### 可复现：ROI 与图像域（HALCON 22.11.4.0）

```hdevelop
read_image (Image, 'your_image.png')
gen_rectangle1 (ROI, 100, 150, 400, 550)
reduce_domain (Image, ROI, ImageROI)
threshold (ImageROI, Bright, 180, 255)
```

`gen_rectangle1` 的坐标顺序是上行、左列、下行、右列。`reduce_domain` 求原图像域与 ROI 的交集，**矩阵尺寸和坐标系不变**；后面的阈值只在有效域内运行。把 `Bright` 的质心直接用于原图坐标是合理的，但若接着 `crop_domain` 则需重新检查坐标。此处 180–255 只是 8 位亮目标的示范阈值，实际要看灰度直方图与漏检样本。

来源：[MVTec `reduce_domain`](https://www.mvtec.com/doc/halcon/2211/en/reduce_domain.html)、[`threshold`](https://www.mvtec.com/doc/halcon/2211/en/threshold.html)，HALCON 算子参考 22.11.4.0。这里是基于官方接口编写的练习，不是教材原文。
