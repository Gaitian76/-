## 可直接使用的知识

特征应当对任务相关变化敏感，对无关变化稳定。区域形状特征包括面积、周长、长宽、方向、圆度和矩；灰度特征包括均值、方差、极值和直方图统计；纹理可用共生矩阵、局部模式或滤波器响应描述。

圆度常写为 $C=4\pi A/P^2$，理想圆接近 1，但像素化和边界噪声会影响周长。主轴方向可由二阶矩求得，近圆形对象的方向不稳定，不应作为可靠姿态。

特征选择流程：先明确缺陷机理 → 候选特征 → 在正常/异常和多工况数据上画分布 → 检查相关性与稳定性 → 选择阈值或模型。不能只选择在训练样本上分得最开的特征。

所有几何特征要说明是在像素坐标还是标定后的物理坐标中计算。

## 课堂补充

### 可复现：筛选目标并读出面积、质心（HALCON 22.11.4.0）

```hdevelop
read_image (Image, 'your_gray_image.png')
threshold (Image, Foreground, 120, 255)
connection (Foreground, Components)
select_shape (Components, Selected, ['area','circularity'], 'and', [200,0.65], [2000,1.0])
area_center (Selected, Area, Row, Column)
```

示例同时要求面积在 200–2000 像素、圆度在 0.65–1 范围；`'and'` 要求两项均满足。`Area`、`Row`、`Column` 是和 `Selected` 中各区域对应的元组；在下游使用前先检查选中对象数。`area_center` 输出的面积单位是像素，不是 mm²；要转物理单位需相机标定和目标平面约束。若目标相互粘连，`connection` 无法自动拆开，应先处理粘连或改用轮廓测量。

来源：[MVTec `select_shape`](https://www.mvtec.com/doc/halcon/2211/en/select_shape.html)、[`area_center`](https://www.mvtec.com/doc/halcon/2211/en/area_center.html)，HALCON 算子参考 22.11.4.0；阈值和范围是练习值。
