# 大四专业课 · 总览

> [!info] 使用说明
> 这是四门大四专业课的入口。课程页负责教材信息与章节导航；46 篇章节笔记均有公开的一手技术来源及可学习的具体知识、练习或论文阅读定位。它们尚不是四本书的逐页摘要，涉及实机/软件的练习也尚待实际验证；详见[[教材正文与来源核验]]。

> [!note] 知识来源层级
> **教材证据**：书名、版本和章节结构来自你保存的封面、版权页与目录图片。  
> **通用工程知识**：章节中的原理与方法是独立整理的专业知识，不冒充教材原文。  
> **公开来源补充**：FANUC、NI、MVTec、SKF、NIST 等资料已逐章链接；故障诊断论文题名/起始页来自你保存的目录照片。  
> **个人知识**：课堂重点、设备型号、实验数据和错题留给你持续补充。

## 推荐学习顺序

1. 用 [[课程 · LabVIEW虚拟仪器设计及应用]] 建立采集、显示、控制和信号处理能力。
2. 用 [[课程 · 机器视觉技术基础]] 完成视觉检测链路。
3. 用 [[课程 · FANUC工业机器人编程操作与仿真]] 把检测结果接入机器人工作站。
4. 用 [[课程 · 设备状态监测与故障诊断技术及其工程应用]] 建立设备健康与维护视角。
