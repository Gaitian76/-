## 课程检查点

- [ ] 能从照明、镜头、相机和接口解释图像质量
- [ ] 能在 HDevelop 中完成采集、ROI、预处理和分割
- [ ] 能选择形状、灰度或纹理特征并验证稳定性
- [ ] 能完成模板匹配、相机标定与几何测量
- [ ] 能说明双目和激光三角测量的基本链路
- [ ] 能把 HALCON 算法集成到 MFC 或 Qt 应用
