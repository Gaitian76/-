# 第02章 · 电阻电路的等效变换

返回 [[课程 · 电路]] · [[电路 · PDF资料与章节导航]]

教材入口：[[电路 第6版 (邱关源) .pdf#page=58|第2章 / §2-1，印刷 p.34 / PDF p.58]]；[[电路 第6版 (邱关源) .pdf#page=59|§2-2 串联和并联，印刷 p.35]]；[[电路 第6版 (邱关源) .pdf#page=67|§2-5 实际电源模型，印刷 p.43]]。

## 核心知识

- “等效”必须说明观察端口：替换前后对**外部电路**呈现同一端口电压—电流关系；被替换部分的内部电压、电流或耗散功率一般不相同。
- 电阻串联时流过相同电流，`R_eq=R_1+R_2+…`；并联时承受相同电压，`1/R_eq=1/R_1+1/R_2+…`。两个正电阻并联可用 `R_eq=R_1R_2/(R_1+R_2)`。
- 实际电压源与实际电流源的模型变换涉及**串联/并联内阻**及其方向：`U_s=I_s R_s`，电阻数值相同。只有端口行为等效，不能直接把理想电压源与理想电流源互换。

## 自拟检查

6 Ω 与 3 Ω 并联，端口等效电阻为多少？**2 Ω**。若端口加 12 V，外部看见总电流 **6 A**；若还要各支路电流，须回原并联电路分别求 2 A 与 4 A。
