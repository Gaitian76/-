# 第05章 · 含有运算放大器的电阻电路

返回 [[课程 · 电路]] · [[电路 · PDF资料与章节导航]]

教材入口：[[电路 第6版 (邱关源) .pdf#page=138|第5章 / §5-1 运放模型，印刷 p.114 / PDF p.138]]；[[电路 第6版 (邱关源) .pdf#page=141|§5-2 比例电路，印刷 p.117]]；[[电路 第6版 (邱关源) .pdf#page=142|§5-3 理想运放电路，印刷 p.118]]。

## 核心知识

- 理想运放输入端不吸收电流，`i_+=i_-=0`；在**负反馈且输出仍在线性工作范围**时，两个输入端电位近似相等，即“虚短”。只有“输入电流为零”不保证虚短，正反馈或饱和时不可套用。
- 标准反相比例电路的同相端接参考地、输入经 `R_in` 到反相端、反馈电阻 `R_f` 从输出接回反相端，此时 `u_o=-(R_f/R_in)u_i`。公式依赖上述接法、理想模型和输出未触及电源轨。

## 自拟检查

在标准反相比例电路中，`R_in=10 kΩ`、`R_f=20 kΩ`、`u_i=0.2 V`，预测 `u_o=-0.4 V`。再检查电源轨是否允许 -0.4 V；若不允许，不能继续把“虚短”用于实际饱和电路。
