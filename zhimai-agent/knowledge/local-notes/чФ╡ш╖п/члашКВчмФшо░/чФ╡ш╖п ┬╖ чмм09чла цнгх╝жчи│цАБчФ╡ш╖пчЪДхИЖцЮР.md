# 第09章 · 正弦稳态电路的分析

返回 [[课程 · 电路]] · [[电路 · PDF资料与章节导航]]

教材入口：[[电路 第6版 (邱关源) .pdf#page=234|第9章 / §9-1 阻抗和导纳，印刷 p.210 / PDF p.234]]；[[电路 第6版 (邱关源) .pdf#page=246|§9-4 功率，印刷 p.222]]；[[电路 第6版 (邱关源) .pdf#page=250|§9-5 复功率，印刷 p.226]]。

## 核心知识

- 在角频率 `ω>0` 的同频正弦稳态、线性理想元件中，`Z_R=R`、`Z_L=jωL`、`Z_C=1/(jωC)`；一端口阻抗定义为同一参考方向下的电压相量/电流相量。电感电抗为正、电容电抗为负。
- 用**有效值相量**时，复功率 `S=U I* = P+jQ`；实际平均功率 `P=UI cosφ`，无功功率 `Q=UI sinφ`。若改用峰值相量，公式前需乘 `1/2`。
- 先算各元件阻抗，再按串、并联或节点/网孔法求相量，最后按同一相量约定还原时域。不同频率的信号须分别求解后在时域叠加。

## 自拟检查

50 Hz 下理想 `0.1 H` 电感的阻抗为 **`j31.4 Ω`**（`ω=2π·50 rad/s`），不是 `31.4 Ω`；前面的 `j` 表示电压相位领先电流 90°。
