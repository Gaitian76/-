# 第08章 · 相量法

返回 [[课程 · 电路]] · [[电路 · PDF资料与章节导航]]

教材入口：[[电路 第6版 (邱关源) .pdf#page=217|第8章 / §8-1 复数，印刷 p.193 / PDF p.217]]；[[电路 第6版 (邱关源) .pdf#page=220|§8-2 正弦量，印刷 p.196]]；[[电路 第6版 (邱关源) .pdf#page=226|§8-4 电路定律的相量形式，印刷 p.202]]。

## 核心知识

- 相量把**同一角频率**的正弦稳态量表示为复数；`x(t)=√2 X cos(ωt+φ)` 在“有效值相量”约定下对应 `X∠φ`。若用峰值相量，模长应是 `√2 X`，两种约定不能混用。
- 选定 `e^{jωt}` 记号后，时间微分对应相量乘 `jω`。因此电感、电容的相量关系可转成代数式，但**暂态**和**不同频率谐波**不可放在同一个相量方程中直接相加。
- KCL、KVL 的相量形式仍须按统一参考方向列写；相位差由复数角度体现，不可仅把有效值当作普通实数相加。

## 自拟检查

`u(t)=10√2 cos(100t+30°) V` 的有效值相量是 **`10∠30° V`**，对应导数的相量为 `j100·10∠30°`。若写成 `10√2∠30°`，那是峰值相量而非有效值相量。
